# Project Rules & Style Guidelines

## LaTeX Resume Tailoring Rule
- ALWAYS use the master `resume.tex` template with `resume.cls` class style for generating job application resumes.
- NEVER alter the document layout, preamble, header centering, or custom `\begin{rSection}` structure.
- Only modify the text content of `Profile Summary`, `Technical Skills`, and `Experience` bullet points to match the target job description & core tech stack.
- The compiled output PDF MUST always be named `Muhammad_Hamza_CV.pdf`.
